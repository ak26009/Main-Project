Cloth Drying Machine Using ESP32S
A smart IoT-based automatic cloth drying system built using the ESP32S microcontroller and a Flutter mobile application.
This system automates the drying process by controlling heating rods, exhaust fans, UV lights, and a motorized drying pole, all managed wirelessly via the app.

🔧 Features
Mobile App Control: Start, stop, and monitor drying remotely.
Automated Drying: ESP32S controls temperature, airflow, and lighting.
Smart Energy Use: Efficient power management for heating and fans.
UV Sterilization: Built-in UV lights for germ-free drying.
Home Automation Ready: Easily integrates into IoT ecosystems.

⚙️ Components Used
Microcontroller: ESP32S
Motor: 125W for rolling poles
Heating Rods: 2 × 150W
UV Lights: 2 × 6W
Exhaust Fans: 2 × 15W
LED Light: 15W
Relays: For component switching
